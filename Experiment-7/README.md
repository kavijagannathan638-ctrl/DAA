# Experiment 7

## Aim

To solve the N-Queens puzzle using backtracking, placing N queens on an N x N chessboard such that no two queens threaten each other.

## Algorithms

- Backtracking N-Queens search
- Safety verification check (`is_safe`)

## Result

The backtracking algorithm successfully found all solutions for N=4, 6, and 8, displaying the visual board representation for the N=4 cases and showing correct backtracks counts.
