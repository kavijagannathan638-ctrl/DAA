# Experiment 8

## Aim

To find the optimal tour for the Travelling Salesman Problem (TSP) using Branch and Bound (with matrix reduction) and brute-force verification.

## Algorithms

- Matrix Reduction algorithm for cost computation
- Brute Force verification search using Permutations

## Result

The minimum cost and the optimal path for the 5-city cost matrix were successfully calculated. The optimal tour is A -> C -> D -> B -> E -> A with a minimum cost of 34.
